## What this teaches

- **values and types:** A value is data; its type determines which operations make sense. JavaScript has primitive values and objects. Example: 3 is a number; '3' is a string; {available:3} is an object.
- **coercion and strict equality:** Coercion converts one type into another. === compares without that conversion; == can convert before comparing. Example: '0' == 0 is true, but '0' === 0 is false.
- **truthiness:** Conditions convert values to true or false. A nonempty string is truthy even when its contents say false. Example: Boolean('false') is true; Boolean('') is false.
- **functions:** A function is reusable behavior with parameters, a return value, and possibly side effects. Example: validateQuantity(3) returns a result; it should not change outside state.
- **control flow:** Control flow determines which statements execute and in what order, using branches, loops, and early returns. Example: Reject an invalid quantity before reserving stock.
- **arrays and objects:** Arrays are ordered collections; objects associate property names with values. Example: A jobs array contains objects with id and status properties.
- **destructuring and spread:** Destructuring extracts fields; spread copies enumerable properties or expands an iterable. Object spread is shallow. Example: {...stock, available:2} creates a new outer object.
- **Map and Set:** Map stores key/value associations; Set stores unique values. They suit lookup and duplicate detection. Example: Index jobs by ID with a Map and track seen IDs with a Set.
- **immutability:** Treat existing data as unchanged and create new values when updating it. Example: Return a new stock object instead of decrementing the input object.
- **operators and precedence:** Operators perform calculations or comparisons. Precedence decides grouping when parentheses are absent. Example: 2 + 3 * 4 evaluates to 14; (2 + 3) * 4 evaluates to 20.
- **strings and numbers:** Strings represent text; numbers represent numeric values. Their operators and conversions can behave differently. Example: '2' + 3 produces '23'; 2 + 3 produces 5.
- **array map filter reduce sort:** map transforms items, filter selects items, reduce combines them, and sort orders them; sort mutates its array. Example: Count completed jobs with reduce; copy before sorting.
- **shallow versus deep copy:** A shallow copy shares nested references; a deep copy duplicates supported nested data. Example: Copying stock with spread still shares stock.metadata.
- **complexity analysis:** Describe how time and memory requirements grow with input size, rather than relying only on one timing. Example: Repeated linear searches may cost more than building an index once.
