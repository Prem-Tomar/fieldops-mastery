## What this teaches

- **let const var:** let and const are block scoped; var is function scoped. const prevents rebinding, not object mutation. Example: const stock={available:3} still permits changing stock.available.
- **scope and hoisting:** Scope controls where bindings can be accessed. Bindings are created before execution, but initialization rules differ. Example: Reading a let binding before initialization throws a ReferenceError.
- **closures:** A function can retain access to bindings from the scope where it was created. Example: A counter function remembers its private count between calls.
- **this call bind apply:** this depends on invocation for ordinary functions; call/apply supply it, and bind creates a bound function. Example: Detaching counter.increment can lose the counter receiver.
- **prototypes and classes:** Objects can inherit property lookup through prototypes. Class syntax builds on this object model. Example: A class method is normally found on the class prototype.
- **own properties:** Own properties exist directly on an object, rather than being inherited from its prototype. Example: Object.hasOwn(counter,'count') distinguishes direct state from inherited methods.
- **ES modules:** JavaScript modules use import/export with explicit dependencies and live exported bindings. Example: An imported counter binding reflects updates made by its exporting module.
- **CommonJS:** Node's CommonJS module system uses require and module.exports; interoperability depends on runtime rules. Example: A .cjs module exports a normalizeStatus function.
- **exceptions and finally:** throw interrupts normal control flow; catch handles errors; finally runs cleanup when the try block exits. Example: A finally block releases a subscription after work throws.
- **iterables and generators:** An iterable produces an iterator; a generator function can yield values lazily and preserve execution state. Example: jobIds(jobs) yields one ID at a time.
- **garbage collection:** The runtime can reclaim objects that are no longer reachable. Exact collection timing is not guaranteed. Example: A lingering subscription closure can retain an otherwise unused job.
- **WeakMap and WeakSet:** Weak collections reference object keys without keeping them alive solely through that collection; they are not enumerable. Example: Associate private metadata with an object using a WeakMap.
- **BigInt and Symbol:** BigInt represents integers beyond ordinary number precision; Symbol creates unique identity values. Example: Two Symbol('job') calls differ; 2n + 3n produces 5n.
