## What this teaches

- **promises:** A Promise represents an eventual fulfilled value or rejection; callbacks run after the current synchronous work. Example: searchJobs('pump') returns a Promise of matching jobs.
- **async await:** async returns a Promise; await pauses that function's continuation while other work can proceed. Example: Await a request without treating CPU-heavy loops as nonblocking.
- **closures:** A function can retain access to bindings from the scope where it was created. Example: A counter function remembers its private count between calls.
- **timers:** Timers schedule callbacks after a delay threshold; execution can be later when the runtime is busy. Example: A 250 ms debounce timer waits before starting search.
- **race conditions:** An outcome depends on timing or ordering between operations that overlap. Example: An old search response arrives after the current query's response.
- **AbortController:** An AbortController sends a cancellation signal to APIs that support it; cancellation remains cooperative. Example: Abort an old fetch and separately prevent stale publication.
- **errors:** Errors describe failed operations; programs need a deliberate policy for reporting and recovering from them. Example: A failed current search shows a retryable error.
- **cleanup:** Cleanup releases resources your operation owns when it completes, fails, or is abandoned. Example: Clear timers, unsubscribe listeners, and close owned cursors.
