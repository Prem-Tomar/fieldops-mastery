## What this teaches

- **event loop:** The event loop coordinates execution of scheduled callbacks around synchronous JavaScript work. Example: A long synchronous report calculation delays other callbacks.
- **microtasks versus timers:** Promise reactions run as microtasks; timer callbacks run through later scheduled tasks. Runtime details still matter. Example: Predict synchronous logging, then a Promise reaction, then a timer.
- **promise combinators:** Promise helpers combine multiple operations with different completion and rejection policies. Example: Compare Promise.all with Promise.allSettled for a batch.
- **error propagation:** A thrown error or rejected Promise must reach a handler that owns the failure policy. Example: Await worker results so rejected jobs do not become unhandled failures.
- **concurrency versus parallelism:** Concurrency overlaps progress; parallelism executes work simultaneously. Async I/O does not itself imply multiple CPU threads. Example: Three network requests can overlap on one JavaScript thread.
- **resource cleanup:** Cleanup releases resources your operation owns when it completes, fails, or is abandoned. Example: Clear timers, unsubscribe listeners, and close owned cursors.
