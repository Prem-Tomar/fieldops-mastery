## What this teaches

- **native components:** Native components map React Native UI descriptions to platform views. Example: Use Text and View rather than browser div elements.
- **Flexbox:** Flexbox lays out items within a container using direction, alignment, and size rules. Example: Arrange technician actions in an adaptive row.
- **safe areas:** Safe areas avoid content being obscured by device cutouts and system UI. Example: Keep the completion button above the bottom inset.
- **navigation:** Navigation manages screen transitions and their history. Example: Open job detail and return to the prior list.
- **deep links:** A deep link routes an external location to a particular application screen. Example: Open a job from a notification.
- **keyboard handling:** Keyboard handling keeps fields and actions usable when the software keyboard changes available space. Example: Scroll the focused notes field into view.
- **platform differences:** Android and iOS can differ in permission, layout, navigation, and lifecycle behavior. Example: Verify the Android back action separately from iOS navigation.
- **accessibility:** Accessibility makes interactions understandable and usable with different input methods and assistive technology. Example: Label controls and support keyboard navigation.
