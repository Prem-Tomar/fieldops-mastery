## Primary learning idea

Durable local evidence drafts

## Precise task

Capture or select a photo, add notes, and store a draft locally. Represent granted, denied, and unavailable permissions. Only display saved after both draft data and a durable photo reference are persisted.

## What this teaches

- **camera and media permissions:** Apps must request and handle platform access to capture or select media. Example: Show recovery when camera permission is denied.
- **local files:** Local files have storage locations and lifetimes; temporary files may not be durable evidence. Example: Copy an owned camera result into an appropriate durable location.
- **local persistence:** Persistence stores data beyond the current process's memory. Example: Reopen the app and recover completion notes.
- **app lifecycle:** The OS can foreground, background, suspend, or terminate a mobile process. Example: Persist a draft before claiming it is saved.
- **async writes:** An asynchronous write finishes later; acknowledgement must reflect actual durable completion. Example: Display saved only after the persistence operation succeeds.
- **secure versus ordinary storage:** Sensitive credentials need protected storage appropriate to the platform; ordinary preferences are not a secret store. Example: Keep session credentials out of unencrypted draft storage.
