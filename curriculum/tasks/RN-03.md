## What this teaches

- **FlatList:** FlatList is a React Native component for efficiently presenting scrollable collections. Example: Use stable IDs and measure a 5,000-job list.
- **virtualization:** Virtualization renders a visible window of a large collection rather than every item. Example: Render only nearby rows in a 10,000-job list.
- **stable keys:** Keys identify siblings across list changes; stable domain IDs avoid mismatched identity. Example: Use job.id rather than a changing array position.
- **gestures:** Gestures translate touch movement into interactions with cancellation and conflict rules. Example: A row swipe opens an action without breaking scrolling.
- **animations:** Animations change visual properties over time and must respect responsiveness and user preferences. Example: Measure a swipe transition under JS load.
- **JS and UI threads:** JavaScript execution and platform UI work have distinct scheduling concerns. Example: A JS stall and a UI rendering stall can have different symptoms.
- **image memory:** Decoded image memory can exceed compressed download size. Example: Resize a large photo for a small thumbnail.
- **Hermes profiling:** Hermes profiling inspects JavaScript work in React Native's JavaScript engine. Example: Find CPU-heavy work in a release-build interaction.
