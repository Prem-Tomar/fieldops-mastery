## What this teaches

- **native modules:** Native modules expose platform functionality through a JavaScript-accessible interface. Example: Expose a small device-uptime API.
- **typed specifications:** A typed native specification describes the interface shared across language boundaries. Example: Declare a native method's parameter and return shapes.
- **code generation:** Code generation produces integration code from a declared interface or schema. Example: Generate native glue from a module specification.
- **JSI concepts:** JSI is an interface enabling JavaScript and native code to interact; it is not a guarantee of cheap or safe synchronous work. Example: Explain why a slow native call can still block interaction.
- **Fabric concepts:** Fabric is React Native's renderer architecture that coordinates React and native view work. Example: Trace how a changed layout reaches the platform view.
- **render commit mount:** React Native rendering calculates a tree, commits an accepted result, then mounts host changes. Example: Distinguish calculating a row from updating its native view.
- **threading:** Threading determines where work executes and how access is coordinated. Example: Keep expensive work off an interaction-critical thread.
- **native build tools:** Native build tools compile and package platform code and dependencies. Example: Use Android tooling and Xcode for platform builds.
