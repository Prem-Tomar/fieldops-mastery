## What this teaches

- **Node streams:** Streams process data incrementally instead of loading the entire payload at once. Example: Stream report rows or attachment bytes.
- **backpressure:** Backpressure slows a producer when its consumer cannot keep up. Example: A slow download prevents unbounded report buffering.
- **pipeline:** A pipeline connects processing stages with error and cleanup coordination. Example: Pipe generated rows through CSV formatting to a response.
- **async iterators:** Async iterators yield values over time through an asynchronous iteration protocol. Example: Read report rows using for await.
- **buffering:** Buffering temporarily accumulates data; uncontrolled buffering can exhaust memory. Example: Limit queued chunks between a database cursor and client.
- **database cursors:** A database cursor incrementally reads query results while owning database resources. Example: Close the cursor when the downloading client disconnects.
- **CSV correctness:** CSV output needs proper quoting, line handling, encoding, and a policy for spreadsheet interpretation. Example: Escape a comma-containing note and handle formula-leading text.
- **cancellation:** Cancellation defines how unfinished work stops and how owned resources are released. Example: Disposed search must not publish a later response.
