# TS-02 — Create reusable typed pagination and projections

Phase: P02 | Order: 6 | Prerequisite: TS-01

## Precise task

Implement Page<T>, Result<T,E>, and pickFields<T,K extends keyof T>(value, keys). Preserve field types in projections. Build one mapped readonly view type and one conditional type for extracting a Result success value.

## Why we are doing this

Shared web/mobile contracts must retain useful type information.

## What you achieve

Reusable primitives with demonstrated inference and documented limits.

## What this teaches

- generics
- constraints
- keyof
- indexed access
- mapped types
- conditional types
- utility types
- structural typing
- readonly

- function types
- overloads
- optional and rest parameters

## Progressive hints

1. Begin with concrete Job and Technician examples.
2. Separate compile-time readonly from runtime freezing.
3. Use the smallest helper signatures that preserve inference.

## Acceptance criteria

- [ ] Invalid field keys fail compilation; valid projections preserve exact types.
- [ ] Show a structural-typing excess-property example and explain its behavior.
- [ ] Explain one safe internal assertion, if required, instead of hiding it.

## Independent mastery challenge

Model a typed event map whose event name determines the corresponding payload.

The coach adds one undisclosed variation after both learners submit their own predictions and implementation evidence. Each learner explains every listed concept, predicts an observable behavior, and demonstrates it in code or an experiment. Fixing the shared product alone does not mark either learner's coverage complete.

## Pair collaboration

Both learners complete the same concepts and criteria. Alternate driver/reviewer on shared integration; use isolated spikes for individual alternatives. The second PR adds tests, a validated alternative, or personal evidence rather than duplicating production code. Review each other's reasoning only after independent predictions are recorded. Pairing is allowed; assisted work remains marked assisted until independently repeated.

## Evidence to submit

Every dimension must reach 2 independently. Failed concepts receive remediation; experience level never waives a basic concept.
